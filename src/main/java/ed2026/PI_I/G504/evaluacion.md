# Evaluación de la práctica integradora 1

## Código fuente - 100 puntos

* Funcionamiento - 50
    * Funciona completamente.

* Resolución algorítmica - 30
    * Se implementaron las estructuras de datos requeridas.
        * Stack específica; solo los métodos necesarios.
        * Queue específico; solo los métodos necesarios.
    * Se implementaron los métodos requeridos.

* Identificación de variables y métodos - 20
    * Se identificaron correctamente las variables y métodos requeridos.
    * Se recomienda utilizar el idioma inglés para nombrar variables y métodos, ya que es una práctica común en la industria del software y facilita la comprensión del código por parte de otros desarrolladores.
    * Se recomienda utilizar nombres que además de describir la funcionalidad, coincidan con los nombres de los métodos en las implementaciones de las estructuras de datos del lenguaje utilizado; los programadores que lean el código podrán relacionar más fácilmente los métodos con las estructuras de datos que representan; un cliente -no programador- no tiene por qué leer el código, de modo que no es necesario que entienda el código para poder usar la aplicación.
